# Editor

Everything in ctrl32 is done from one installed application: you draw the
screens, declare the variables, write the logic and download the result into
the board. The editor renders with the same code as the firmware, so the
screen you design is — pixel for pixel — the screen the board shows.

- [Layout and how to work in it](editor.md) — the windows, the toolbar,
  simulation and going online
- [Variables](variables.md) — VAR and RVAR, types, deadband, and where
  values come from
- [The project file](project-format.md) — what a project is on disk, and
  why that means you can put it in version control

**New to it?** [Your first project](tutorial.md) builds one from an empty
file in half an hour, with no hardware needed until the last step.
