# ctrl32 documentation

The help of **ctrl32** - the editor, the runtimes, the function blocks,
the widgets and the vision blocks. The same pages open in the editor with
F1 and on [ctrl32.com](https://ctrl32.com).

```
docs/        the pages (English markdown) and their pictures
landing/     tutorials and examples
mkdocs.yml   the order of the pages
```

A local preview: `pip install mkdocs` and `mkdocs serve` in this folder.
